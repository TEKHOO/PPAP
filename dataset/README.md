# PPAP Dataset
For PPI Affinity Prediction

## Download Instructions
To access the PPAP Dataset:
1. Visit the official download page: [https://www.pdbbind-plus.org.cn/download](https://www.pdbbind-plus.org.cn/download).
2. **Register** for a free account on the website if you do not already have one.
3. **Log in** to your account.
4. Navigate to the **Other Datasets** section.
5. Locate and download the PPAP Dataset.
